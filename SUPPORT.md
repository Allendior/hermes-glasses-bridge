# Support

This is an experimental, owner-operated companion for Hermes and Meta AI
glasses. It is not an official Meta or Nous Research product.

For reproducible bugs, open a GitHub issue with:

- the commit you tested
- macOS and Android versions
- Hermes version
- glasses model and firmware
- the exact command or screen where it failed
- logs with every key, token, private path, transcript, and voice recording
  removed

Use GitHub's private vulnerability reporting instead of an issue for anything
security-sensitive. Questions about Meta developer access, Speech API approval,
firmware, or Meta account policy belong with Meta because this project cannot
change those systems.
