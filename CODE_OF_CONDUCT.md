# Community Guidelines

Be direct, useful, and respectful.

- Critique code and decisions, not people.
- Do not publish another person's credentials, recordings, transcripts, private
  network details, or account information.
- Do not use this project to bypass platform consent, access controls, or local
  law.
- Report security problems privately through GitHub Security Advisories.
- Maintainers may remove spam, harassment, unsafe instructions, or material
  that exposes someone else's private data.

If you disagree with a decision, explain the technical tradeoff and bring a
reproducible test or a smaller alternative. That is the fastest way to improve
the project.
